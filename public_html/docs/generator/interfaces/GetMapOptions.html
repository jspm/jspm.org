    OptionalcollapseLinkedScopes

    collapseLinkedScopes?: boolean

    Hoist the shared mappings of each linkedScopes group into the top-level imports.

    Linked scopes resolve identically, so by default the map repeats their mappings under every linked scope URL. With this option the shared mappings are output once as top-level imports and the group's scopes are dropped. Groups hoist in linkedScopes declaration order, and a mapping that conflicts with an existing top-level import stays in its group's scopes.

    Default

    false
